# ファイル分割について

.inoファイルが500行を超えると流石に読むのが億劫になる（と思っている）．  
[26th_Software_Sample](https://github.com/torica-org/26th_Software_Sample)を参照

## 手順

1. Arduino IDEで`.ino`ファイルを開き，タブを追加する．

|<img src="https://europe1.discourse-cdn.com/arduino/original/4X/2/3/d/23d8b9f2e647c1661cfa06b1f7ceafd2d93f2d52.png" width="500px">|
|:--:|
|タブの追加|

名前を`〇〇.cpp`と`〇〇.h`として2つ作成する．

2. `.ino`から分離したい特定の機能を持つ関数と変数を別ファイルの`.cpp`ファイルに移植する．
3. `.ino`からアクセスしたいものに限り，`.h`ファイルに変数の`extern`宣言と関数のプロトタイプ宣言をする（`.cpp`内部で完結する場合は，`.h`ファイルに宣言を書く必要はない）．
4. `.ino`および`.cpp`ファイルで`#include "〇〇.h"`を書く．

## 注意
- `.h`や`.cpp`では`#include <Arduino.h>`を忘れないようにする（自動で読み込まれない）．
- できるだけ`.cpp`から他の`.cpp`へのアクセスが起こる構造にしない（複雑になる）．
- `enum`の宣言などでは多重定義が起こる可能性がある（エラーが非常に読み解きにくい）．
- Arduino IDEのコンパイラが保持するキャッシュにも注意する．

## 参考
### enumやstructの移植
`test.ino`に以下のような`enum`と`struct`が宣言されていたとする．
> test.ino
```cpp
enum MyEnum {
  OK,
  NG,
};
MyEnum myEnum = NG;

struct EulerAngles {  // オイラー角用の構造体.
  float roll, pitch, yaw;
};
volatile EulerAngles angles;
```

これを`.h`および`.cpp`ファイルに移植する．

> test.ino
```cpp
#include "test.h"

void setup() {
  myEnum = OK;
  
  Serial.printf("%.5f, %.5f, %.5f\n", angles.roll, angles.pitch, angles.yaw);
}

```

> test.h
```cpp
#include <Arduino.h>

enum MyEnum { // 型の宣言
  OK,
  NG,
};
extern MyEnum myEnum; // 別の場所で定義があることを宣言

struct EulerAngles { // 型の宣言
  float roll, pitch, yaw;
};
extern volatile EulerAngles angles; // 別の場所で定義があることを宣言
```

> test.cpp
```cpp
#include <Arduino.h>
#include "test.h"

MyEnum myEnum = NG; // `MyEnum`型の変数の定義

volatile EulerAngles angles; // `EulerAngles`型の変数の定義
```
