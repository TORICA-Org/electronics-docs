# カリキュラム

## 概要
電装班で楽しく活動し続けてもらうための教育カリキュラムです．
鳥人間コンテスト滑空機の電装に必要な知識であることよりも，「楽しいこと」「わかりやすいこと」を一番に考えました．

## 1. マイコン初級編

### 目的
- Raspberry Pi Picoの開発に必要な基礎知識を得る．

### 到達目標
- 自分のPCにRaspberry Pi Picoの開発に必要な環境を構築できる
- Raspberry Pi PicoとPCを正しく接続し，プログラムを書き込める
- Raspberry Pi PicoをArduino IDEの基本的な関数を用いて制御できる

### 計画
|順序|タイトル|内容|
|:--:|:--:|:--:|
|1|準備をする|開発環境の構築|
|2|プログラムを書き込む|ボードとCOMポートの選択|
|3|LEDを点滅させる|`pinMode()`と`digitalWrite()`，`delay()`の使用|
|4|LEDの明るさを変える|`analogWrite()`の使用|
|5|PCと文字列通信をする|`Serial`の使用|
|6|外部スイッチを使う|`digitalRead()`と`INPUT_PULLUP`の使用|
|7|ボリュームを使う|`analogRead()`と`analogReadResolution()`の使用|
|8|ブザーを使う|`tone()`の使用|
|9|電子ピアノを作る|ここまでの応用|
