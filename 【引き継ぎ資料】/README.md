# 【引き継ぎ資料】
- 基本的なスタンスは「報告書」です
  - 「何を」「どんな目的で」「どう作ったか」
- あらゆる内容を報告します
  - 「大会での動き・結果」「全体システム」「基板の配置・固定」「ピトー管・補正値」など
- 「報告」ではなく「電装班に蓄積すべき知識」である場合には，[electronics-docs](https://github.com/torica-org/electronics-docs/tree/main)直下の「プリント基板」「ソフトウェア」などに資料として残します
  - 似たような内容がこのディレクトリと[electronics-docs](https://github.com/torica-org/electronics-docs/tree/main)に重複するのは構いません
