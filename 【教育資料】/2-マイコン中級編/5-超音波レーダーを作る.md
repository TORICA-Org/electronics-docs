# 5 - 超音波レーダーを作る

中級編の締めくくりとして，これまでに学んだ「サーボモーター」「超音波センサー」「シリアル通信」を組み合わせて，SF映画に出てくるような **「超音波レーダー」** を作ってみましょう！

<img src="https://fb00d14c.delivery.rocketcdn.me/wp-content/uploads/2015/07/Arduino-Radar-Complete.jpg" alt="超音波レーダーの完成イメージ" width="600" />

サーボモーターで超音波センサーを左右に往復回転させながら，それぞれの角度で障害物までの距離を測定します．
測定したデータをPCに送信し，PC上の描画ソフト（Processing）を使って，リアルタイムにレーダー画面を描画します．

---

## 必要なもの
- Raspberry Pi Pico
- サーボモーター（FS90）
- 超音波センサー（HC-SR04）
- 抵抗 1kΩ（1本）
- 抵抗 2kΩ または 2.2kΩ（1本）（見つからなかったら、1kΩ抵抗２本でもよいらしい）
- ブレッドボード
- ジャンパー線
- USBケーブルとPC
- パソコンソフト **Processing** (後述のやり方でインストールします)

---

## 配線方法
サーボモーターと超音波センサーをブレッドボード上で同時に配線します．
3章で説明した通り，超音波センサーのEchoピンは分圧抵抗を通してPicoのGPIOに接続します．

### サーボモーター（FS90）の接続
- **茶色（GND）** $\rightarrow$ Picoの **GND**
- **赤色（5V電源）** $\rightarrow$ Picoの **VBUS**（40番ピン）
- **オレンジ色（信号）** $\rightarrow$ Picoの **GP16**（21番ピン）

### 超音波センサー（HC-SR04）の接続
- **VCC** $\rightarrow$ Picoの **VBUS**（40番ピン）
- **GND** $\rightarrow$ Picoの **GND**
- **Trig** $\rightarrow$ Picoの **GP14**（19番ピン）
- **Echo** $\rightarrow$ 1kΩ抵抗を通して **GP15**（20番ピン）へ繋ぐ．さらにGP15の列から2kΩ（または2.2kΩ）抵抗を通して **GND** へ繋ぎます（分圧回路）．

## やり方

### 1. マイコン側のプログラムを準備する
Arduino IDEに以下のプログラムをコピーし，Picoに書き込みましょう．
このプログラムは，サーボを1度ずつ動かしながら距離を測り，`角度,距離.` という形式（例：`90,25.`）でPCへデータを送り続けます．めっちゃ早く流れて醜いので数値変えるか気合で見るのもよいかもしれない.

```cpp
#include <Servo.h>
#include <HCSR04.h> // 3章でインストールした超音波センサー用ライブラリ

const int trigPin = 14;
const int echoPin = 15;
const int servoPin = 16;

UltraSonicDistanceSensor distanceSensor(trigPin, echoPin);
Servo myServo;

void setup() {
  Serial.begin(9600); // Processingと合わせるため、通信速度は9600にします
  myServo.attach(servoPin);
}

void loop() {
  // 15度から165度まで、サーボを1度ずつ回しながら測定して送信
  for (int i = 15; i <= 165; i++) {
    myServo.write(i);
    delay(30); // サーボが動くのを少し待つ
    
    int distance = (int)distanceSensor.measureDistanceCm();
    
    // 測定エラー（マイナス値）や、40cmより遠い場合は限界値（40cm）とする
    if (distance < 0 || distance > 40) {
      distance = 40; 
    }
    
    // Processingが解釈しやすいフォーマットで送信（例： 90,25. ）
    Serial.print(i);
    Serial.print(",");
    Serial.print(distance);
    Serial.print(".");
  }
  
  // 165度から15度まで逆方向に回しながら測定して送信
  for (int i = 165; i >= 15; i--) {
    myServo.write(i);
    delay(30);
    
    int distance = (int)distanceSensor.measureDistanceCm();
    
    if (distance < 0 || distance > 40) {
      distance = 40;
    }
    
    Serial.print(i);
    Serial.print(",");
    Serial.print(distance);
    Serial.print(".");
  }
}
```

### 2. PC側の描画ソフト「Processing」を準備する
PC上でデータを緑色のかっこいいレーダー画面としてビジュアル化するために，**Processing（プロセッシング）** というソフトを使います．

#### レーダー画面の実行イメージ
<img src="https://fb00d14c.delivery.rocketcdn.me/wp-content/uploads/2015/07/Radar-Print-Screen-03.jpg" alt="Processingのレーダー画面イメージ" width="600" />

#### Processingのインストール方法
1. [Processing公式サイト](https://processing.org/download/) から，お使いのPCのOS（Windows等）用のソフトをダウンロードします（無料です）．
2. ダウンロードしたZIPファイルを解凍し，フォルダの中にある `processing.exe` を実行して起動します．

#### Processing用のプログラム
Processingが起動したら，最初から開いているエディタ画面に以下のコードをすべてコピー＆ペーストします．

```java
import processing.serial.*;

Serial myPort;
String angle="";
String distance="";
String data="";
String noObject;
float pixsDistance;
int iAngle, iDistance;
int index1=0;
PFont orcFont;

void setup() {
  // レーダーを表示するウインドウのサイズ（1280x720画素）
  size(1280, 720); 
  smooth();
  
  // 【重要】Picoが接続されているCOMポート番号に書き換えてください（例: "COM3", "COM4" など）
  myPort = new Serial(this, "COM4", 9600); 
  
  // '.' が届くまでバッファにデータを溜める設定
  myPort.bufferUntil('.'); 
  
  // 画面に表示するフォントを作成（PCの標準フォントを使用）
  orcFont = createFont("sans-serif", 30);
}

void draw() {
  fill(98, 245, 31);
  textFont(orcFont);
  
  // 暗い緑色の半透明の四角を描くことで、古い線の残像（レーダーのスイープ効果）を作ります
  noStroke();
  fill(0, 4); 
  rect(0, 0, width, height - height * 0.065); 
  
  fill(98, 245, 31); // 鮮やかな緑色
  
  // 各種描画関数を呼び出す
  drawRadar(); 
  drawLine();
  drawObject();
  drawText();
}

// マイコンからシリアルポートにデータが届いたときに自動で呼ばれる関数
void serialEvent (Serial myPort) {
  // '.' までのデータを一塊として読み取る
  data = myPort.readStringUntil('.');
  if (data != null) {
    data = data.substring(0, data.length() - 1); // 末尾の '.' を消去
    index1 = data.indexOf(","); // カンマの位置を探す
    
    if (index1 > 0) {
      angle = data.substring(0, index1); // カンマより前（角度）を取り出す
      distance = data.substring(index1 + 1, data.length()); // カンマより後（距離）を取り出す
      
      // 文字列を整数型（int）に変換して変数に入れる
      iAngle = int(angle);
      iDistance = int(distance);
    }
  }
}

// レーダーの背景（円弧と角度の補助線）を描く関数
void drawRadar() {
  pushMatrix();
  translate(width / 2, height - height * 0.074); // 画面下部中央を原点にする
  noFill();
  strokeWeight(2);
  stroke(98, 245, 31);
  
  // 同心円の円弧を描く（10cm, 20cm, 30cm, 40cmに相当）
  arc(0, 0, (width - width * 0.0625), (width - width * 0.0625), PI, TWO_PI);
  arc(0, 0, (width - width * 0.27), (width - width * 0.27), PI, TWO_PI);
  arc(0, 0, (width - width * 0.479), (width - width * 0.479), PI, TWO_PI);
  arc(0, 0, (width - width * 0.687), (width - width * 0.687), PI, TWO_PI);
  
  // 各角度（30度おき）の放射状の線を引く
  line(-width / 2, 0, width / 2, 0);
  line(0, 0, (-width / 2) * cos(radians(30)), (-width / 2) * sin(radians(30)));
  line(0, 0, (-width / 2) * cos(radians(60)), (-width / 2) * sin(radians(60)));
  line(0, 0, (-width / 2) * cos(radians(90)), (-width / 2) * sin(radians(90)));
  line(0, 0, (-width / 2) * cos(radians(120)), (-width / 2) * sin(radians(120)));
  line(0, 0, (-width / 2) * cos(radians(150)), (-width / 2) * sin(radians(150)));
  popMatrix();
}

// 検出された障害物を赤い線で描く関数
void drawObject() {
  pushMatrix();
  translate(width / 2, height - height * 0.074);
  strokeWeight(9);
  stroke(255, 10, 10); // 赤色
  pixsDistance = iDistance * ((height - height * 0.1666) * 0.025); // cmをピクセル幅に変換
  
  // 40cm未満に障害物がある場合、その角度・場所に赤い線を描く
  if (iDistance < 40) {
    line(pixsDistance * cos(radians(iAngle)), -pixsDistance * sin(radians(iAngle)), 
         (width - width * 0.505) * cos(radians(iAngle)), -(width - width * 0.505) * sin(radians(iAngle)));
  }
  popMatrix();
}

// 現在スキャンしている方向を示す緑色のビームを描く関数
void drawLine() {
  pushMatrix();
  strokeWeight(9);
  stroke(30, 250, 60); // 明るい緑
  translate(width / 2, height - height * 0.074);
  line(0, 0, (height - height * 0.12) * cos(radians(iAngle)), -(height - height * 0.12) * sin(radians(iAngle)));
  popMatrix();
}

// 画面の下部に角度や距離の数値をテキスト表示する関数
void drawText() {
  pushMatrix();
  if (iDistance > 40) {
    noObject = "Out of Range";
  } else {
    noObject = "In Range";
  }
  
  fill(0, 0, 0);
  noStroke();
  rect(0, height - height * 0.0648, width, height); // 数値表示エリアの背景を黒にする
  
  fill(98, 245, 31);
  textSize(18);
  text("10cm", width - width * 0.3854, height - height * 0.0833);
  text("20cm", width - width * 0.281, height - height * 0.0833);
  text("30cm", width - width * 0.177, height - height * 0.0833);
  text("40cm", width - width * 0.0729, height - height * 0.0833);
  
  textSize(24);
  text("Object: " + noObject, width - width * 0.875, height - height * 0.0277);
  text("Angle: " + iAngle + " °", width - width * 0.48, height - height * 0.0277);
  text("Distance: ", width - width * 0.26, height - height * 0.0277);
  if (iDistance < 40) {
    text("        " + iDistance + " cm", width - width * 0.225, height - height * 0.0277);
  }
  
  // 各ラインの角度（30°, 60°など）のテキストを描く
  textSize(18);
  fill(98, 245, 60);
  translate((width - width * 0.4994) + width / 2 * cos(radians(30)), (height - height * 0.0907) - width / 2 * sin(radians(30)));
  rotate(-radians(-60));
  text("30°", 0, 0);
  resetMatrix();
  
  translate((width - width * 0.503) + width / 2 * cos(radians(60)), (height - height * 0.0888) - width / 2 * sin(radians(60)));
  rotate(-radians(-30));
  text("60°", 0, 0);
  resetMatrix();
  
  translate((width - width * 0.507) + width / 2 * cos(radians(90)), (height - height * 0.0833) - width / 2 * sin(radians(90)));
  rotate(radians(0));
  text("90°", 0, 0);
  resetMatrix();
  
  translate(width - width * 0.513 + width / 2 * cos(radians(120)), (height - height * 0.07129) - width / 2 * sin(radians(120)));
  rotate(radians(-30));
  text("120°", 0, 0);
  resetMatrix();
  
  translate((width - width * 0.5104) + width / 2 * cos(radians(150)), (height - height * 0.0574) - width / 2 * sin(radians(150)));
  rotate(radians(-60));
  text("150°", 0, 0);
  popMatrix(); 
}
```

## 3. 動作確認

1. PicoとPCをUSBケーブルで接続します．
2. Arduino IDEを開き，PicoのCOMポートを確認します（例: `COM4`）．

4. Processingの左上にある **「実行（Play）ボタン」** を押します．

## 練習問題

### 1. レーダーが捉えた「障害物までの最も近い距離」に応じて，初級編で使った圧電スピーカーから警告ブザーが鳴る仕組みをマイコン側に追加しなさい．
[ヒント]
- スピーカーの接続：GP15をEchoピンに使っているため，スピーカーは別のピン（例えば **GP17** など）に繋ぎます．
- 距離が近くなるほど，警告音のテンポ（delayの間隔）を短くしたり，周波数を高くしたりして警告を表現してみましょう．

```cpp
#include <Servo.h>
#include <HCSR04.h>

const int trigPin = 14;
const int echoPin = 15;
const int servoPin = 16;
const int speakerPin = 17; // スピーカーをGP17に接続

UltraSonicDistanceSensor distanceSensor(trigPin, echoPin);
Servo myServo;

void setup() {
  Serial.begin(9600);
  myServo.attach(servoPin);
  pinMode(speakerPin, OUTPUT);
}

void loop() {
  // 15度〜165度スキャン
  for (int i = 15; i <= 165; i++) {
    myServo.write(i);
    delay(30);
    
    int distance = (int)distanceSensor.measureDistanceCm();
    if (distance < 0 || distance > 40) {
      distance = 40; 
    }
    
    // 距離が15cm未満のときはスピーカーから「ピピッ」と短い警告音を出す
    if (distance < 15) {
      tone(speakerPin, 1000); // 1000Hzの音
      delay(10);
      noTone(speakerPin);
    }
    
    Serial.print(i);
    Serial.print(",");
    Serial.print(distance);
    Serial.print(".");
  }
  
  // 165度〜15度スキャン
  for (int i = 165; i >= 15; i--) {
    myServo.write(i);
    delay(30);
    
    int distance = (int)distanceSensor.measureDistanceCm();
    if (distance < 0 || distance > 40) {
      distance = 40;
    }
    
    if (distance < 15) {
      tone(speakerPin, 1000);
      delay(10);
      noTone(speakerPin);
    }
    
    Serial.print(i);
    Serial.print(",");
    Serial.print(distance);
    Serial.print(".");
  }
}
```

### 2. 【応用】「離れた場所にある超音波レーダーからデータを取得する」システムを作成しなさい．
送信側マイコン（Pico A：超音波レーダー側）で測定した障害物との距離データをUART通信で受信側マイコン（Pico B：手元の表示器側）に送信し，受信側（Pico B）でそのデータに応じて制御を行います．
距離が 15cm 未満ならPico Bの内蔵LEDを点灯させ，それ以外なら消灯させなさい．また，受信した距離データをPCのシリアルモニタに表示しなさい．

[ヒント]
- 送信側（Pico A）では，測定した距離（小数）を `Serial1.println()` を使って改行付きの文字列データとして送信します．
- 受信側（Pico B）では，`Serial1.readStringUntil('\n')` を使ってデータを受信し，`.toFloat()` で数値（小数）に変換してからLEDの制御やPCへの出力を行います．

<details>
<summary>[解答例]</summary>
<!--この下に1行空行を挟む-->

**送信側（Pico A：センサー測定＋データ送信）**
```cpp
#include <HCSR04.h>

const int trigPin = 14;
const int echoPin = 15;

UltraSonicDistanceSensor distanceSensor(trigPin, echoPin);

void setup() {
  Serial1.begin(9600); // 受信側（Pico B）とのUART通信を開始
}

void loop() {
  // 距離を測定
  float distance = distanceSensor.measureDistanceCm();
  
  // 正常に測定できた場合（0cm以上の場合）のみ送信する
  if (distance >= 0) {
    Serial1.println(distance); // 改行コード付きで距離データを送信
  }
  
  delay(200); // 0.2秒ごとに送信
}
```

**受信側（Pico B：データ受信＋LED・シリアル制御）**
```cpp
const int ledPin = LED_BUILTIN;

void setup() {
  Serial.begin(115200); // PCへの表示用
  Serial1.begin(9600);  // Pico Aからのデータ受信用
  pinMode(ledPin, OUTPUT);
}

void loop() {
  if (Serial1.available() > 0) {
    // 改行コード '\n' まで一括で文字列として読み取る
    String receivedStr = Serial1.readStringUntil('\n');
    receivedStr.trim(); // 余計な空白や改行（\r）を取り除く
    
    // 文字列を小数型（float）に変換
    float distance = receivedStr.toFloat();
    
    // PCのシリアルモニタへ距離を表示
    Serial.print("Remote Distance: ");
    Serial.print(distance);
    Serial.println(" cm");
    
    // 距離が15cm未満のときはLEDを点灯、それ以外は消灯
    if (distance < 15.0) {
      digitalWrite(ledPin, HIGH);
    } else {
      digitalWrite(ledPin, LOW);
    }
  }
}
```
