# 4 - マイコンとマイコンの間で通信する

これまでは，マイコンとPC（シリアルモニタ）の間で通信を行ってきましたが，今回は **「マイコン同士」** を繋いで直接データをやり取りさせてみましょう！

飛行機の制御システムやロボット開発など，電装システムが大きくなると，1つのマイコンですべてのセンサーやモーターを処理するのが難しくなります．
そこで，複数のマイコンに役割を分担させ，お互いに通信しながら協力させます．その最も基本となる通信規格が **UART（ユアート/ユーアート）** です．

---

## UART通信の基本ルール

UART通信では，データを送るための **TX（Transmit：送信）** ピンと，データを受け取るための **RX（Receive：受信）** ピンの2本の信号線を使います．

### ⚠️ 配線の3大原則
1. **TXとRXは「クロス」して繋ぐ！**
   - 送信側の送信ピン（TX）は，受信側の受信ピン（RX）に繋ぎます．
   - 送信側の受信ピン（RX）は，受信側の送信ピン（TX）に繋ぎます．
2. **GND同士を必ず繋ぐ！**
   - 電圧の「基準（0V）」が共通になっていないと，正しいデータが伝わりません．必ずマイコン同士のGNDを繋いでください．
3. **通信速度（ボーレート）を合わせる！**
   - お互いがデータを送受信するテンポ（速度）を同じ値（例：`9600` や `115200`）に設定する必要があります．

---

## Raspberry Pi PicoのUARTピン
Raspberry Pi Picoには，PCとの通信（USBシリアル）用の `Serial` とは別に，他の機器と通信するためのハードウェアUARTピンが最初から用意されています．
Arduino IDEでは，これを **`Serial1`** という名前で簡単に呼び出すことができます．

#### Raspberry Pi Picoのピン配置（ピンアウト）
<img src="https://www.raspberrypi.com/documentation/microcontrollers/images/pico-pinout.svg" alt="Raspberry Pi Pico Pinout" width="600" />

- デフォルトの `Serial1` ピン：
  - **TX** $\rightarrow$ **GP0**（1番ピン）
  - **RX** $\rightarrow$ **GP1**（2番ピン）

---

## 配線方法
マイコン（Raspberry Pi Pico）を2台使って通信します．

#### UART接続の概念（TXとRXはクロスする）
```mermaid
graph LR
    subgraph Pico A (送信側)
    TX_A["GP0 (TX)"]
    GND_A[GND]
    end
    subgraph Pico B (受信側)
    RX_B["GP1 (RX)"]
    GND_B[GND]
    end
    TX_A --> RX_B
    GND_A --- GND_B
```

1. **Pico Aの GP0 (TX)** $\rightarrow$ **Pico Bの GP1 (RX)** に接続
2. **Pico Aの GP1 (RX)** $\rightarrow$ **Pico Bの GP0 (TX)** に接続（双方向通信をする場合）
3. **Pico Aの GND** $\rightarrow$ **Pico Bの GND** に接続

*※2台のPicoは，それぞれUSBケーブルでPCに接続して電源を供給します．*

> [!TIP]
> **Picoが1台しか手元にない場合（ループバックテスト）：**
> 自分の **GP0 (TX)** と **GP1 (RX)** をジャンパー線で直接繋ぐことで，自分で送信したデータを自分で受信するテストができます．

---

## プログラム

### 1. 送信側（Pico A）のプログラム
データを1秒おきに送り続けるプログラムです．

```cpp
void setup() {
  // 外部通信用（Serial1）を通信速度9600で開始します
  Serial1.begin(9600); 
}

void loop() {
  // シリアル通信で文字「A」を送信する
  Serial1.print('A');
  
  delay(1000); // 1秒待つ
}
```

### 2. 受信側（Pico B）のプログラム
届いたデータを読み取って，PCのシリアルモニタへ表示するプログラムです．

```cpp
void setup() {
  Serial.begin(115200);  // PCとの通信（USBシリアル）を開始
  Serial1.begin(9600);   // マイコン同士の通信（Serial1）を開始
}

void loop() {
  // Serial1 にデータが届いているか確認する
  if (Serial1.available() > 0) {
    // 届いたデータを1バイト読み取る
    char receivedData = Serial1.read();
    
    // 読み取った文字をPCのシリアルモニタに表示する
    Serial.print("Received: ");
    Serial.println(receivedData);
  }
}
```

---

## 動作確認
1. 送信側（Pico A）に「送信側のプログラム」を書き込みます．
2. 受信側（Pico B）に「受信側のプログラム」を書き込みます．
3. **受信側（Pico B）を接続しているCOMポートを選択し，シリアルモニタを開きます**（通信速度は `115200 baud`）．
4. 1秒ごとにシリアルモニタに「Received: A」と表示されれば通信成功です！

## 練習問題

### 1. 送信側（Pico A）にタクトスイッチを1つ追加し，「スイッチが押されている間は文字 'H' を，離されている間は文字 'L' を送信する」プログラムを作成しなさい．
[ヒント]
- スイッチの配線：片方を **GP2**，もう片方を **GND** に接続します．
- 送信側で `pinMode(2, INPUT_PULLUP)` を設定し，`digitalRead(2)` の値で送信する文字を切り替えます．

<details>
<summary>[送信側（Pico A）解答]</summary>
<!--この下に1行空行を挟む-->

```cpp
const int buttonPin = 2;

void setup() {
  Serial1.begin(9600);
  pinMode(buttonPin, INPUT_PULLUP);
}

void loop() {
  if (digitalRead(buttonPin) == LOW) {
    Serial1.print('H'); // 押されているときは 'H'
  } else {
    Serial1.print('L'); // 離されているときは 'L'
  }
  delay(50); // 誤作動防止とデータ送信量を抑えるための短いウェイト
}
```
</details>

### 2. 受信側（Pico B）のプログラムを書き換えて，送信側から 'H' が届いたときはPico内蔵LEDを点灯し，'L' が届いたときは消灯させる「遠隔スイッチ」を完成させなさい．

<details>
<summary>[受信側（Pico B）解答]</summary>
<!--この下に1行空行を挟む-->

```cpp
const int ledPin = LED_BUILTIN;

void setup() {
  Serial1.begin(9600);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  if (Serial1.available() > 0) {
    char data = Serial1.read();
    
    if (data == 'H') {
      digitalWrite(ledPin, HIGH); // LED点灯
    } else if (data == 'L') {
      digitalWrite(ledPin, LOW);  // LED消灯
    }
  }
}
```
</details>

### 3. 送信側で好きな文字列を送信し，受信側でその末尾に"（Pico Bからの返送）"と追記して送り返すプログラムを作成し，シリアルモニタで動作を確認しなさい．
[ヒント]
- 改行コード `\n` が届くまで文字列を一括で読み込むには，`Serial1.readStringUntil('\n')` を使います．
- この問題では，Pico A $\rightarrow$ Pico B だけでなく，Pico B $\rightarrow$ Pico A の双方向の配線（Pico AのRXとPico BのTX）が必要です．

<details>
<summary>[解答]</summary>
<!--この下に1行空行を挟む-->

**送信側（Pico A）**
```cpp
void setup() {
  Serial.begin(115200); // パソコンへの表示用
  Serial1.begin(9600);  // Pico Bとの通信用
}

void loop() {
  // Pico Bへ文字列を送信（末尾に改行をつけます）
  Serial1.println("Hello from Pico A");
  
  delay(100); // Pico Bからの返答を少し待つ
  
  // 返答データがあるか確認
  if (Serial1.available() > 0) {
    String response = Serial1.readStringUntil('\n');
    Serial.print("Response: ");
    Serial.println(response); // シリアルモニタに表示
  }
  
  delay(3000); // 3秒待つ
}
```

**受信側（Pico B）**
```cpp
void setup() {
  Serial1.begin(9600);
}

void loop() {
  if (Serial1.available() > 0) {
    // 改行コードまで一気に読み取る
    String data = Serial1.readStringUntil('\n');
    
    // 文字列の余計な空白や改行を削除する
    data.trim();
    
    // 文字列を結合して、Pico Aに送り返す
    String sendBack = data + " (Pico Bからの返送)";
    Serial1.println(sendBack);
  }
}
```
</details>

### 4. 送信側でカンマ区切りで複数の数値データを送信し，受信側で全ての数値に1を足して送り返すプログラムを作成し，シリアルモニタで動作を確認しなさい．
[ヒント]
- 文字列の分割は，`indexOf()` でカンマの位置を探し，`substring()` を使って切り出すことで行えます．
- 整数と小数で使う型変換の関数が違います（整数なら `.toInt()`，小数なら `.toFloat()`）．

<details>
<summary>[解答]</summary>
<!--この下に1行空行を挟む-->

**送信側（Pico A）**
```cpp
void setup() {
  Serial.begin(115200);
  Serial1.begin(9600);
}

void loop() {
  Serial1.println("10,20,30"); // 3つの数値をカンマ区切りで送信
  
  delay(100);
  
  if (Serial1.available() > 0) {
    String response = Serial1.readStringUntil('\n');
    Serial.print("Result: ");
    Serial.println(response);
  }
  
  delay(3000);
}
```

**受信側（Pico B）**
```cpp
void setup() {
  Serial1.begin(9600);
}

void loop() {
  if (Serial1.available() > 0) {
    // 1行読み取り
    String data = Serial1.readStringUntil('\n');
    data.trim();
    
    // カンマの位置を探す
    int comma1 = data.indexOf(',');
    int comma2 = data.indexOf(',', comma1 + 1);
    
    // カンマが2個とも見つかった場合
    if (comma1 != -1 && comma2 != -1) {
      // 部分文字列を切り出して整数に変換し、1を足す
      int val1 = data.substring(0, comma1).toInt() + 1;
      int val2 = data.substring(comma1 + 1, comma2).toInt() + 1;
      int val3 = data.substring(comma2 + 1).toInt() + 1;
      
      // 再びカンマ区切りにして送り返す
      Serial1.print(val1);
      Serial1.print(",");
      Serial1.print(val2);
      Serial1.print(",");
      Serial1.println(val3);
    }
  }
}
```
</details>

### 5. 送信側（Pico A）・受信側（Pico B）のプログラムを書き換えて，受信側（Pico B）のPico内蔵LEDとそれに接続されたサーボモーターを同時に制御しなさい．
[ヒント]
- LEDのON/OFFは，"0"か"1"の文字列データを`int`型に変換して判断しましょう．
- サーボモーターの駆動する角度はLEDの"0/1"に続けて，数値で送りましょう．
- 以下のようなデータ構造にすると良いでしょう．
```
// "○": 0/1, "△":サーボモーターの角度
"○, △△△"

// 例) LED: ON, サーボモーター: 45°回転
"1, 45"
```
- サーボを動かすためには，Pico B側のプログラムで `#include <Servo.h>` や `myServo.attach(ピン番号)` などの設定を忘れないようにしましょう．

<details>
<summary>[解答]</summary>
<!--この下に1行空行を挟む-->

**送信側（Pico A）**
```cpp
void setup() {
  Serial1.begin(9600);
}

void loop() {
  // 1. LED: ON(1), サーボ: 45度
  Serial1.println("1,45");
  delay(3000);
  
  // 2. LED: OFF(0), サーボ: 135度
  Serial1.println("0,135");
  delay(3000);
}
```

**受信側（Pico B）**
```cpp
#include <Servo.h>

Servo myServo;
const int ledPin = LED_BUILTIN;
const int servoPin = 16; // サーボの信号線をGP16に接続

void setup() {
  Serial1.begin(9600);
  pinMode(ledPin, OUTPUT);
  myServo.attach(servoPin);
}

void loop() {
  if (Serial1.available() > 0) {
    String data = Serial1.readStringUntil('\n');
    data.trim();
    
    int comma = data.indexOf(',');
    if (comma != -1) {
      // カンマの前後を切り出して数値に変換
      int ledState = data.substring(0, comma).toInt();
      int servoAngle = data.substring(comma + 1).toInt();
      
      // 制御を実行
      digitalWrite(ledPin, ledState);
      myServo.write(servoAngle);
    }
  }
}
```
</details>
