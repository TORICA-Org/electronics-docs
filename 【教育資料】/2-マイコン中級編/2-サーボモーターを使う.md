# 2 - サーボモーターを使う

サーボモーターとは，角度を指定して回転させることのできる特殊なモーターです．
角度の指定にはPWMという`analogWrite()`のときにも出てきたものを使いますが，ちょっと面倒です．

そこで，今回は「ライブラリ」というものを使ってみましょう！
ライブラリを使うことで，難しい計算をすることなく，簡単に角度を指定して動かすことができるようになります．

## 必要なもの
- Raspberry Pi Pico
- サーボモーター（FS90）
- ブレッドボード
- ジャンパー線
- USBケーブルとPC

## やり方

### 1. ブレッドボード上で配線する
サーボモーター（FS90）からは3本のコードが出ています．それぞれの色に合わせて，以下のようにPicoと接続します．

#### サーボモーターの配線ピンアウト
<img src="https://newbiely.com/images/tutorial/servo-motor-pinout.jpg" alt="サーボモーターのピンアウト" width="400" />

- **茶色（GND）** $\rightarrow$ Picoの **GND**（例：38番ピンなど）
- **赤色（電源）** $\rightarrow$ Picoの **VBUS**（40番ピン：USBからの5V出力）
- **オレンジ色（信号）** $\rightarrow$ Picoの **GP16**（21番ピン）

#### 配線図
<img src="https://newbiely.com/images/tutorial/raspberry-pi-pico-servo-motor-wiring-diagram.jpg" alt="Picoとサーボモーターの配線図" width="600" />

> [!WARNING]
> サーボモーターは一時的に大きな電流を消費します．Picoの `3V3`（3.3V出力）ピンに繋ぐと，マイコンが再起動したり故障したりする原因になります．必ず **VBUS（5V）** ピンに接続してください．

### 2. プログラムを準備する
Arduino IDEに以下のプログラムをコピーし，マイコンに書き込みましょう．
Arduinoには標準でサーボモーターを動かすための「Servo」ライブラリが用意されているため，新しくインストールする必要はありません．

```cpp
#include <Servo.h>  // サーボモーター用のライブラリを読み込む

Servo myServo;      // サーボモーターを制御するための「オブジェクト（変数）」を作成

const int servoPin = 16;  // サーボの信号線を接続したピン（GP16）

void setup() {
  myServo.attach(servoPin);  // どのピンにサーボがつながっているかを設定
}

void loop() {
  // 0度から180度まで，1度ずつ動かす
  for (int pos = 0; pos <= 180; pos += 1) {
    myServo.write(pos);              // サーボを指定した角度に動かす
    delay(15);                       // サーボが動ききるのを少し待つ
  }
  
  delay(1000); // 180度の位置で1秒待つ

  // 180度から0度まで，1度ずつ戻す
  for (int pos = 180; pos >= 0; pos -= 1) {
    myServo.write(pos);              // サーボを指定した角度に動かす
    delay(15);
  }
  
  delay(1000); // 0度の位置で1秒待つ
}
```

### 3. 動作確認
書き込みが完了すると，サーボモーターの軸がゆっくりと往復運動を始めます．
もし動かない場合は，配線の色（特に赤と茶が逆になっていないか）を確認してください．

## 練習問題

### 1. 初級編で使ったボリューム（可変抵抗器）を使って，ボリュームの回転に合わせてサーボモーターの角度（0度〜180度）がリアルタイムに変わるプログラムを作成しなさい．
[ヒント]
- ボリュームの配線：両端を `3V3` と `GND`，真ん中のピンを `GP26(ADC0)` に繋ぎます．
- `analogRead(26)` で読み取った値（0〜4095）を，サーボの角度（0〜180）に変換するには `map()` 関数を使うと便利です．
- `map(value, fromLow, fromHigh, toLow, toHigh)`

<details>
<summary>[解答]</summary>
<!--この下に1行空行を挟む-->

```cpp
#include <Servo.h>

Servo myServo;

const int servoPin = 16;
const int potPin = 26; // ボリュームを繋ぐアナログピン（GP26）

void setup() {
  myServo.attach(servoPin);
}

void loop() {
  // ボリュームの値を読み取る（0 〜 4095）
  int val = analogRead(potPin);            
  
  // 0〜4095 の値を 0〜180 の角度に変換する
  int angle = map(val, 0, 4095, 0, 180); 
  
  // サーボを動かす
  myServo.write(angle);                  
  
  delay(15); // 動作を安定させるための短いウェイト
}
```
</details>
