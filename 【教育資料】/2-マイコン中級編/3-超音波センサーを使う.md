# 3 - 超音波センサーを使う

超音波センサーを使うと，目の前にある物体や壁までの距離を測ることができます．
これを使えば，障害物を避けて走るロボットや，手が近づくと自動で開くゴミ箱などが作れるようになります！

ここでは，超音波センサーの定番である **HC-SR04** を使って，距離を測ってみましょう．

<img src="https://fb00d14c.delivery.rocketcdn.me/wp-content/uploads/2022/02/HC-SR04-Ultrasonic-Sensor-Arduino-Tutorial.jpg" alt="HC-SR04超音波センサー" width="500" />

## 必要なもの
- Raspberry Pi Pico
- 超音波センサー（HC-SR04）
- 抵抗 1kΩ（1本）
- 抵抗 2kΩ または 2.2kΩ（1本）
- ブレッドボード
- ジャンパー線
- USBケーブルとPC

---

## 超音波センサーの仕組みと「分圧」の注意点

### 1. 超音波センサーの仕組み
HC-SR04は，**Trig（トリガー）** ピンから超音波を発射し，それが物体に反射して戻ってくるまでの時間を **Echo（エコー）** ピンのHIGHの時間として出力します．

#### 動作原理
<img src="https://fb00d14c.delivery.rocketcdn.me/wp-content/uploads/2022/01/How-Ultrasonic-Sensor-Working-Principle-Explained-1024x525.jpg" alt="超音波センサーの動作原理" width="600" />

### ⚠️ 超重要な注意点（分圧について）
HC-SR04は **5V** の電気で動作します．そのため，Echoピンから返ってくる信号の電圧も **5V** になります．
しかし，Raspberry Pi Picoのピンは最大 **3.3V** までしか耐えられません．5Vを直接繋ぐと，Picoが壊れてしまう可能性があります！

そこで，**「分圧（ぶんあつ）」** という仕組みを使います．
1kΩと2kΩの抵抗を直列に繋ぎ，その間から電気を取り出すことで，5Vの電圧を安全な **約3.3V** に下げてPicoに入力します．

$$5\text{V} \times \frac{2\text{k}\Omega}{1\text{k}\Omega + 2\text{k}\Omega} \approx 3.33\text{V}$$

## やり方

### 1. ブレッドボード上で配線する
以下のように接続します．抵抗の向き（左右）はありません．

1. **VCC** $\rightarrow$ Picoの **VBUS**（40番ピン・5V出力）
2. **GND** $\rightarrow$ Picoの **GND**（例：38番ピンなど）
3. **Trig** $\rightarrow$ Picoの **GP14**（19番ピン）
4. **Echo** からの配線：
   - Echoピンからブレッドボードの空いている列に繋ぐ．
   - そこから **1kΩの抵抗** を通して，別の列（**GP15** に繋ぐ列）へ渡す．
   - **GP15** に繋いだ列から，さらに **2kΩ（または2.2kΩ）の抵抗** を通して **GND** へ繋ぐ．
   - **GP15**（20番ピン）から，1kΩと2kΩの抵抗の間の列へジャンパー線を繋ぐ．

> **配線のイメージ：**
> `Echoピン` $\rightarrow$ `[ 1kΩ抵抗 ]` $\rightarrow$ (ここから `GP15` へ) $\rightarrow$ `[ 2kΩ抵抗 ]` $\rightarrow$ `GND`

### 2. プログラムを準備する（まずはライブラリなしで動かす）
Arduino IDEに以下のプログラムをコピーし，マイコンに書き込みましょう．
このプログラムは，超音波が往復する時間を直接計測して距離を計算します．

#### 距離の計算式
<img src="https://fb00d14c.delivery.rocketcdn.me/wp-content/uploads/2022/01/How-Ultrasonic-Sensor-calculates-distance-from-object.jpg" alt="超音波センサーによる距離計算式" width="600" />

```cpp
const int trigPin = 14; // Trigピン（GP14）
const int echoPin = 15; // Echoピン（GP15）

void setup() {
  Serial.begin(115200);   // パソコンとの通信（シリアルモニタ）を開始
  pinMode(trigPin, OUTPUT);
  pinMode(echoPin, INPUT);
}

void loop() {
  // 1. トリガーピンから10マイクロ秒間超音波を発射する
  digitalWrite(trigPin, LOW);
  delayMicroseconds(2);
  digitalWrite(trigPin, HIGH);
  delayMicroseconds(10);
  digitalWrite(trigPin, LOW);

  // 2. エコーピンがHIGHになっている時間（往復時間：マイクロ秒）を測る
  // pulseIn() は指定したピンがHIGHになっている時間をマイクロ秒単位で返す関数です
  long duration = pulseIn(echoPin, HIGH);

  // 3. 往復時間から距離（cm）を計算する
  // 音速は約340m/s = 0.034cm/μs です．
  // 距離 ＝ (往復時間 × 音速) ÷ 2 （往復なので半分にする）
  float distance = (duration * 0.034) / 2;

  // 4. シリアルモニタに結果を表示する
  Serial.print("Distance: ");
  Serial.print(distance);
  Serial.println(" cm");

  delay(500); // 0.5秒ごとに測定
}
```

### 3. 動作確認（ライブラリなし）
マイコンに書き込んだ後，Arduino IDEの右上の虫眼鏡マークから **「シリアルモニタ」** を開きます．
通信速度（ボーレート）が **「115200 baud」** に設定されていることを確認してください．
センサーの前に手をかざしたり遠ざけたりすると，距離の数値が変化することを確認しましょう！

---

### 4. ライブラリを導入して使ってみよう
中級編の目標である「ライブラリ」をインストールして，もっとすっきりしたプログラムに書き換えてみましょう！

#### ライブラリのインストール手順
1. Arduino IDEの左メニューにある **「ライブラリマネージャ」**（本棚のようなアイコン）をクリックします．
2. 検索バーに `HCSR04` と入力します．
3. **「HCSR04 by Martin Sosic」** というライブラリを探し，**「インストール」** をクリックします．
   （依存する他のライブラリのインストールを求められたら「Install all」を選択してください）

#### ライブラリを使ったプログラム
インストールが完了したら，以下のプログラムに書き換えてみましょう．

```cpp
#include <HCSR04.h> // インストールした超音波センサーライブラリを読み込む

const int trigPin = 14;
const int echoPin = 15;

// 超音波センサーオブジェクトを作成（Trigピン，Echoピンの順で指定）
UltraSonicDistanceSensor distanceSensor(trigPin, echoPin);

void setup() {
  Serial.begin(115200);
}

void loop() {
  // ライブラリの関数を使って距離（cm）を直接取得する
  double distance = distanceSensor.measureDistanceCm();

  // 測定限界を超えた場合などはマイナスの値が返ることがあります
  if (distance >= 0) {
    Serial.print("Distance: ");
    Serial.print(distance);
    Serial.println(" cm");
  } else {
    Serial.println("Out of range");
  }

  delay(500);
}
```
ライブラリを使うことで，音速の計算やトリガーピンのON/OFF制御などをライブラリが裏で勝手にやってくれるため，とてもシンプルなコードになりました！

## 練習問題

### 1. 測定した距離が 10cm 未満になったときだけ，Pico本体のLED（GP25 または LED_BUILTIN）が点灯し，それ以外のときは消灯するプログラムを作成しなさい．
[ヒント]
- Picoの基板上のLEDは `LED_BUILTIN`（またはピン番号 `25`）で制御できます．
- `if`文を使って条件分岐を行います．

<details>
<summary>[解答]</summary>
<!--この下に1行空行を挟む-->

```cpp
#include <HCSR04.h>

const int trigPin = 14;
const int echoPin = 15;
const int ledPin = LED_BUILTIN; // Pico内蔵LED

UltraSonicDistanceSensor distanceSensor(trigPin, echoPin);

void setup() {
  Serial.begin(115200);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  double distance = distanceSensor.measureDistanceCm();

  if (distance >= 0) {
    Serial.print("Distance: ");
    Serial.print(distance);
    Serial.println(" cm");

    // 10cm未満なら点灯，それ以外は消灯
    if (distance < 10.0) {
      digitalWrite(ledPin, HIGH);
    } else {
      digitalWrite(ledPin, LOW);
    }
  }

  delay(100);
}
```
