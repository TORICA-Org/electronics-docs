# 8 - 電子ピアノを作る
ピアノをやってみます。
いったんドレを鳴らし、だんだんと鍵盤の数をふやしてみましょう。

## 必要なもの
- Raspberry pi pico
- タクトスイッチ
- 圧電スピーカー（他励式）
- ブレッドボード
- ジャンパー線
- PC
- USBケーブル

## やり方

### 1.ブレッドボード上で配線する

#### 配線の手順

1.Picoを挿す：ブレッドボードの真ん中の溝をまたぐようにPicoを深く挿す。

2.スピーカーを繋ぐ

 - スピーカーの片方の足をGP15の列に挿す。
 - もう片方の足をGNDの列に挿す。

3.ボタンを繋ぐ

 - ボタン（ド）：片方をGP2、もう片方をGNDの列に挿す。
 - ボタン（レ）：片方をGP3、もう片方をGNDの列に挿す。
   図みたいに挿す。

 #### 今回使う関数
-  `dijitalRead()`は、指定したピンに「電気が来ているか（HIGH:1）」、それとも「電気が逃げてゼロになっているか（LOW:0）」を読み取る関数です。
- `tone()`はスピーカーに「電気の波」を送り出す命令です。tone(SPEALER_PIN, 周波数）
-  `noTone`は`tone`が作り出している「電気のON/OFFの波（振動）」を完全にストップさせる命令です。


### 2.プログラムを準備する

```cpp
// ピン番号の定義（PicoのGP番号をそのまま書きます）
const int SPEAKER_PIN = 15;
const int BUTTON_DO = 2;
const int BUTTON_RE = 3;

void setup() {
  // スピーカーのピンを出力用に設定
  pinMode(SPEAKER_PIN, OUTPUT);
  
  // ボタンのピンを入力＋プルアップ（難しい抵抗パーツを省略する設定）に設定
  pinMode(BUTTON_DO, INPUT_PULLUP);
  pinMode(BUTTON_RE, INPUT_PULLUP);
}

void loop() {
  // digitalReadは、ボタンが押されると「LOW（0）」になります
  if (digitalRead(BUTTON_DO) == LOW) {
    tone(SPEAKER_PIN, 262); // 262Hz（ド）の音を鳴らす
  } 
  else if (digitalRead(BUTTON_RE) == LOW) {
    tone(SPEAKER_PIN, 294); // 294Hz（レ）の音を鳴らす
  } 
  else {
    noTone(SPEAKER_PIN);    // どのボタンも押されていなければ音を止める
  }
  
  delay(10); // ほんの少しだけ休む（誤作動防止）
}
```
### 3.動作確認
ドレの音が鳴ったら次に進みましょう。

### 4.ドレミファソまで鳴らす

#### 配線の手順
- 使うピン： GP2（ド）、GP3（レ）、GP4（ミ）、GP5（ファ）、GP6（ソ）
- すべてのボタンの片方の足は、近くの GND に繋ぎます。(先ほどの図のように）

#### プログラムの準備
```cpp
const int SPEAKER_PIN = 15;
const int BUTTON_DO = 2;
const int BUTTON_RE = 3;
const int BUTTON_MI = 4;
const int BUTTON_FA = 5;
const int BUTTON_SO = 6;

void setup() {
  pinMode(SPEAKER_PIN, OUTPUT);
  pinMode(BUTTON_DO, INPUT_PULLUP);
  pinMode(BUTTON_RE, INPUT_PULLUP);
  pinMode(BUTTON_MI, INPUT_PULLUP);
  pinMode(BUTTON_FA, INPUT_PULLUP);
  pinMode(BUTTON_SO, INPUT_PULLUP);
}

void loop() {
  if (digitalRead(BUTTON_DO) == LOW) {
    tone(SPEAKER_PIN, 262);
  } else if (digitalRead(BUTTON_RE) == LOW) {
    tone(SPEAKER_PIN, 294);
  } else if (digitalRead(BUTTON_MI) == LOW) {
    tone(SPEAKER_PIN, 330);
  } else if (digitalRead(BUTTON_FA) == LOW) {
    tone(SPEAKER_PIN, 349);
  } else if (digitalRead(BUTTON_SO) == LOW) {
    tone(SPEAKER_PIN, 392);
  } else {
    noTone(SPEAKER_PIN);
  }
  delay(10);
}
```

### 5.1オクターブまでいきます

#### 配線の手順
- 使うピン：GP2（ド）, GP3（レ）, GP4（ミ）, GP5（ファ）, GP6（ソ）, GP7（ラ）, GP8（シ）, GP9（ド）
- すべてのボタンの片方の足はすべてGNDにつなぎます。（先ほどの図のように）

#### プログラムの準備
```cpp
const int SPEAKER_PIN = 15;

// 使うピンの番号を箱（配列）に並べて入れる
const int BUTTON_PINS[] = {2, 3, 4, 5, 6, 7, 8, 9};

// 音の高さ（周波数）を順番に入れる（ドレミファソラシド）
const int TONES[] = {262, 294, 330, 349, 392, 440, 494, 523};

// 鍵盤の数（今回は8個）
const int KEY_COUNT = 8;

void setup() {
  pinMode(SPEAKER_PIN, OUTPUT);
  
  // 8個のボタンの設定を一気に自動で行う（for文）
  for (int i = 0; i < KEY_COUNT; i++) {
    pinMode(BUTTON_PINS[i], INPUT_PULLUP);
  }
}

void loop() {
  bool pressed = false; // ボタンが押されたかどうかの目印

  // 0番目から7番目のボタンまで順番にチェック
  for (int i = 0; i < KEY_COUNT; i++) {
    if (digitalRead(BUTTON_PINS[i]) == LOW) {
      tone(SPEAKER_PIN, TONES[i]); // 押されたボタンに対応する音を鳴らす
      pressed = true;
      break; // 1つでも押されていたら、残りのチェックは飛ばす
    }
  }

  // どのボタンも押されていなかったら音を止める
  if (!pressed) {
    noTone(SPEAKER_PIN);
  }

  delay(10);
}
```
### 動作確認
すべての音階が聞こえたら成功です。
