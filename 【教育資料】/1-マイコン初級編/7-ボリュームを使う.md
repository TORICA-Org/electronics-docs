# 7 - ボリュームを使う

ここでは, ボリューム（可変抵抗）と`analogRead()`を使えるようになってもらいます. 

ボリュームの使い方を[このサイト](https://inagidenshi.shop-pro.jp/?mode=f9)で確認してください. 

ボリュームを使って明るさを制御するにはPWM制御という制御方法を理解する必要があります. 

[このサイト](https://www.ele-lab.com/led7.php)で確認しましましょう. 

ボリュームをつないだピンに入力される電圧はアナログです. PWM制御を行うためには, これをデジタルに変換する必要があります. 

アナログは「連続的に変化する値」です. 
例えば、ボリュームを回したときの電圧は0V～3.3Vの間をなめらかに変化します。

一方, デジタルは「数値として表された値」です。
マイコンは電圧をそのまま理解できないため, A/Dコンバータを用いて数値に変換してから処理します. 

そのために必要なのがA/Dコンバータです. A/Dコンバータはアナログをデジタルに変更するもので, ラズピコの31,32,34番ピン（ADC0,1,2）と書いてあるピンに内蔵されています.

これで0V ~ 3.3Vの入力電圧（アナログ）を0 ~ 4095の数値（デジタル）に変換できます. 

### プログラムを準備する
以下の図のように配線し, Arduino IDEにコードをコピーしてください
#### 注意　
- ラズピコのA/Dコンバータの分解能（どれくらい細かく測れるか）は12bitですが，Arduino IDE上で使用しているライブラリのデフォルトの分解能が10bitなので，12bitに設定を変える必要があります.
- `analogRead()`と`analogWrite()`を必ず[このサイト](https://www.musashinodenpa.com/arduino/ref/index.php)確認してください. 上で書いた内容が詳しく書いてあります.
- 今回はボリュームの値をPWM用の値にする際, 16で割っていますが, Arduino IDEには値の変換をしてくれる`map()`というものがあります. これも上のサイトで確認し, 使ってみてください. 
```cpp
int ledPin = 15;
int vrPin = 26;  // 可変抵抗(ADC0)

void setup(){
	analogReadResolution(12);  // 分解能を12bitに設定
}

void loop(){
  // 可変抵抗の値(0~4095)を読む
  int sensor_val = analogRead(vrPin);

  // PWM制御用の値(0～255)に変換
  int brightness = sensor_val/16;

  // LEDの明るさを変更
  analogWrite(ledPin, brightness);
}
```

## 練習問題
### 1. ボリュームを回すとLEDの点滅速度が変わるコードを作りましょう. 
3でLEDを点滅させてみたと思います. 今回はボリュームを用いて, その点滅速度を変化させてみましょう. 

<details>
<summary>[解答]</summary>
<!--この下に1行空行を挟む-->

```cpp
int ledPin = 15;
int vrPin = 26;

void setup(){
pinMode(ledPin, OUTPUT);
}

void loop(){
  int waitTime = analogRead(vrPin);

  digitalWrite(ledPin, HIGH);
  delay(waitTime);

  digitalWrite(ledPin, LOW);
  delay(waitTime);
}
```
</details>

### 2. PC上に数値が表示され, ボリュームの値とPC上の値が一致したらLEDが光るコードを作りましょう. 
5でPCと通信してみたと思います. ここではその知識も使ってみましょう. 

PCに表示する目標の値は任意.

[ヒント]
- 完全に値を一致させるのは難しいので, 許容範囲を決めておきましょう.

(例) 誤差が100以内ならOK → 目標値: 2000, 現在値:1950の時は値が一致しているとみなせる.  
- 上の操作をするために, 絶対値を求める`abs()`（詳しくはArduino 日本語リファレンス）を使いましょう.
- 何もしないとシリアルモニタの表示が速すぎて見づらいため, 工夫して見やすくしてみましょう. 
<details>
<summary>[解答]</summary>
<!--この下に1行空行を挟む-->

```cpp
const int ledPin = 15;
const int vrPin = 26;
int target = 2000;

void setup(){
  pinMode(ledPin, OUTPUT);
  Serial.begin(9600);

  Serial.print("目標値: ");
  Serial.println(target);
}

void loop(){
  int sensor_val = analogRead(vrPin);

  Serial.print("現在値: ");
  Serial.println(sensor_val);

  // 誤差が100以内ならOK
  if(abs(sensor_val - target) <= 100){
    digitalWrite(ledPin, HIGH);
  }
  else{
    digitalWrite(ledPin, LOW);
  }

  //シリアルモニタを見やすくする（何もしないと現在値の表示が速すぎて見づらい）
  delay(500);
}
```
</details>
