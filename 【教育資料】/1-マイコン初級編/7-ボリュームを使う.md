# 7 - ボリュームを使う

ここでは, ボリューム（可変抵抗）と`analogRead()`を使えるようになってもらいます. 

ボリュームの使い方を[このサイト](https://inagidenshi.shop-pro.jp/?mode=f9)で確認してください. 

ボリュームを使って明るさを制御するにはPWM制御という制御方法を理解する必要があります. 

[このサイト](https://www.ele-lab.com/led7.php)で確認しましましょう. 

ボリュームをつなぐピンに入力される入力電圧はアナログです. PWM制御を行うためには, これをデジタルに変換する必要があります. 

そのために必要なのがA/Dコンバータです. A/Dコンバータはアナログをデジタルに変更するもので, ラズピコの31,32,34番ピン（ADC0,1,2）と書いてあるピンに内蔵されています.

これで0V ~ 3.3Vの入力電圧（アナログ）を0 ~ 255の数値（デジタル）に変換できます. 

### プログラムを準備する
以下の図のように配線し, Arduino IDEにコードをコピーしてください
#### 注意　
- ラズピコのA/Dコンバータの分解能（どれくらい細かく測れるか）は12bitですが，Arduino IDE上で使用しているライブラリのデフォルトの分解能が10bitなので，12bitに設定を変える必要があります.
- `analogRead()`と`analogWrite()`を必ず[このサイト](https://www.musashinodenpa.com/arduino/ref/index.php)確認してください. 上で書いた内容が詳しく書いてあります. 
```cpp
int ledPin = 15;
int volumePin = 26;  // 可変抵抗(ADC0)

void setup(){
	analogReadResolution(12);  // 分解能を12bitに設定
}

void loop(){
  // 可変抵抗の値(0~4095)を読む
  int sensor_val = analogRead(volumePin);

  // PWM制御用の値(0～255)に変換
  int brightness = sensor_val/16;

  // LEDの明るさを変更
  analogWrite(ledPin, brightness);
}
```
