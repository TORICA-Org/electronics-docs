# 5 - PCと通信をする
`Serial`を使います。

Arduinoを使っていると、「PCとデータをやり取りしたい！」と思うことがあります。
そんなときに使うのが Serial 通信です。

Serial通信を使うと

- PC → マイコンへデータを送る
- マイコン → PCへデータを送る

ということができるようになります。

最初は少し難しそうに見えますが、実際にやることはかなりシンプルです。

## 必要なもの
PC
マイコン

## やり方
最初に、`setup()` の中で通信速度を設定します。

### 1．プログラムを準備する

```cpp
void setup() {
  Serial.begin(9600);
}
```
- この 9600 は通信速度です。
- つまり一秒間に9600ビット、例として一秒間に約960回文字を送れます。(1文字に約10ビット必要）
- PC側とArduino側で同じ値にしておく必要があります。
- `setup()`の中で必ず一回実行する必要があります。

これで「通信を始める準備」ができました。

### 2．PCにデータを送る

準備ができたら、まずはマイコンからPCへメッセージを送っていましょう。
`setup()`の中に送れば、起動した瞬間に一度だけ表示されます。

```cpp
void setup() {
  Serial.begin(9600);
  
  // 起動時に一度だけPCへ挨拶を送る
  Serial.println("Hello World!");
}

void loop() {
  // ここに繰り返しやりたいことを書く
}
```
Hello World!とシリアルモニタの表示されれば、成功です‼！‼！

`Serial.println("文字列")`:　PCの画面に文字を表示し、自動的に改行してくれます。

`Serial.print("文字列")`:　改行せず続けて表示したいときに使います。
　　　　　　　     　       
                  　　　　　　　　　　　　改行したいときは、("文字列\n")。

 #### シリアルモニタの開き方
 ##### 画面の右上にある虫眼鏡のアイコンをクリック。

### 3.　PCからのデータを受け取る
次に、PCから送られたデータを確認する仕組みを`loop()`に書き足します。
「データが来ているかを確認する」→　「読む」という2ステップ

```cpp
void loop() {
  // もしPCからデータが届いていたら（0より大きければ）
  if (Serial.available() > 0) {
    
    // 届いたデータを1つ読み取って変数に入れる
    char incomingData = Serial.read();
    
    // 読み取ったデータをそのままPCに送り返してみる（確認用）
    Serial.print("Received: ");
    Serial.println(incomingData);
  }
}
```
- 流れとしては`Serial.available()`でPCからデータが届いているかを確認し、届いているデータの数を返します。
- `if(Serial.available() > 0)`という条件式で使いもしデータが届いていたら読み取るという感じ。
- `Serial.read()`は届いているデータの中から、一番先頭の一文字を読み取ります。
- 一度読み取るとどのデータは保存場所から消えます（次の文字が先頭になります)。
- `loop()`関数に入っているので、上記のことを繰り返しながら文字を読み取る流れになります。

シリアルモニタで好きな英数字(例：A）を打ち込んで、下の画面にReturn:Aが表示されれば、PCからマイコンデータが届き、それをマイコンが正しく処理して送り返させています。
