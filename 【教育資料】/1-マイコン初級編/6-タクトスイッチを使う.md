# 6 - タクトスイッチを使う
ここでは, タクトスイッチと`digitalRead()`を使えるようになってもらいます. 

まずは, タクトスイッチがどんなものか, どんな構造をしているかといったことを理解するために[このサイト](https://inagidenshi.shop-pro.jp/?mode=f5)を読んでみましょう. 

タクトスイッチの見た目や内部構造がなんとなく理解できたと思います. 百聞は一見にしかずということで早速タクトスイッチを使ってLEDを制御してみましょう.

```cpp
int ledPin = 15;  // LEDを15番ピンに
int inPin = 16;   //タクトスイッチを16番ピンに
int val = 0;      // 読み取った値を保持する変数

void setup() {
  Serial.begin(9600);        // シリアルポートを9600bpsで開く
  pinMode(ledPin, OUTPUT);   // LED用に出力に設定
  pinMode(inPin, INPUT);     // スイッチ用に入力に設定
}

void loop() {
  val = digitalRead(inPin);  // 入力ピンを読む
  Serial.println(val);       //読み取った値をシリアルモニターに表示
  digitalWrite(ledPin, val); // LEDのピンを読み取った値に変更
}
```
このプログラムの流れは, `digitalRead()`でinPinがHIGHかLOWかを読み, それを変数valに格納. その後`digitalWrite`で変数valをledPinに読み込ませることでLEDを制御するといった感じです. 

他に, このコードで不明なものは, 例のごとく[このサイト](https://www.musashinodenpa.com/arduino/ref/)で確認してみてください. 

これで, タクトスイッチの使い方と`digitalRead()`の使い方をなんとなく理解できたと思います.

  //スイッチを押した時

    led =1-led;

  }
