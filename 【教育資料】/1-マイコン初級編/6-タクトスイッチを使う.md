# 6 - タクトスイッチを使う
ここでは, タクトスイッチと`digitalRead()`を使えるようになってもらいます. 

まずは, タクトスイッチがどんなものか, どんな構造をしているかといったことを理解するために[このサイト](https://inagidenshi.shop-pro.jp/?mode=f5)を読んでみましょう. 

タクトスイッチの見た目や内部構造がなんとなく理解できたと思います. 百聞は一見にしかずということで早速タクトスイッチを使ってLEDを制御してみましょう.

```cpp
int ledPin = 15;  // LEDを15番ピンに
int inPin = 16;   //タクトスイッチを16番ピンに
int val = LOW;      // 読み取った値を保持する変数

void setup() {
  Serial.begin(9600);        // シリアルポートを9600bpsで開く
  pinMode(ledPin, OUTPUT);   // LED用に出力に設定
  pinMode(inPin, INPUT);     // スイッチ用に入力に設定
}

void loop() {
  val = digitalRead(inPin);  // 入力ピンを読む
  Serial.println(val);       //読み取った値をシリアルモニターに表示
  digitalWrite(ledPin, val); // LEDのピンを読み取った値に変更
}
```
このプログラムの流れは, `digitalRead()`でinPinがHIGHかLOWかを読み, それを変数valに格納. その後`digitalWrite`で変数valをledPinに読み込ませることでLEDを制御するといった感じです. 

他に, このコードで不明なものは, 例のごとく[このサイト](https://www.musashinodenpa.com/arduino/ref/)で確認してみてください. 

これで, タクトスイッチの使い方と`digitalRead()`の使い方をなんとなく理解できたと思います. 

## 練習問題
### 1. スイッチを押したらLEDが光り続けるコードを作りましょう
懐中電灯などはスイッチを押すと光り続けると思います. それを実践してみましょう. 

<details>
<summary>[解答]</summary>
<!--この下に1行空行を挟む-->

```cpp
int ledPin = 15;
int inPin = 16;

int button = LOW;
int beforebutton = LOW;
int led = LOW;

void setup() {
  pinMode(inPin, INPUT);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  button = digitalRead(inPin);
  if (button == HIGH && beforebutton == LOW) {
    if (led == LOW){
      led = HIGH;
    }
    else{
      led = LOW;
    }
  }
  digitalWrite(ledPin, led);
  beforebutton = button;
  delay(100);
}
  ```
</details>

### 2. スイッチを1回押すごとに，　LEDの状態が「消灯」→「暗く点灯」→「明るく点灯」→「消灯」とループするようにしなさい.
[ヒント]
- LEDの状態を`LOW`と`HIGH`の2つだけではなく，`0`，`1`，`2`の3段階の状態で管理します
- 4章で学んだ`analogWrite()`を活かして，出力を各モードに応じた明るさに調整します

<details>
<summary>[解答]</summary>
<!--この下に1行空行を挟む-->
  
```cpp
int ledPin = 15;
int inPin = 16;

int button = LOW;
int beforebutton = LOW;
// LEDのON/OFFではなく、0, 1, 2の「モード」を管理するモード変数を定義
int mode = 0; 

void setup() {
  pinMode(inPin, INPUT);
  pinMode(ledPin, OUTPUT);
}

void loop() {
  button = digitalRead(inPin);
  
  // 1問目で使った「ボタンが押された瞬間」の判定ロジックをそのまま活用
  if (button == HIGH && beforebutton == LOW) {
    mode++; // ボタンが押されるたびにモードを1増やす
    
    if (mode > 2) {
      mode = 0; // モード変数が2（最大）を超えたら、0（消灯）に戻す
    }
  }

  // 現在のモード変数に応じて、analogWrite() で明るさを変える
  if (mode == 0) {
    analogWrite(ledPin, 0);   // 消灯
  } else if (mode == 1) {
    analogWrite(ledPin, 30);  // 暗く点灯（ホタル点滅の応用）
  } else if (mode == 2) {
    analogWrite(ledPin, 255); // 最大輝度で点灯
  }

  beforebutton = button;
  delay(100);
}
  ```
