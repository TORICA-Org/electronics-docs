# カリキュラム

## 概要
電装班で楽しく活動し続けてもらうための教育カリキュラムです．
鳥人間コンテスト滑空機の電装に必要な知識であることよりも，
「楽しいこと」，「わかりやすいこと」，そして「興味を持ち続けられること」を一番に考えました．

## 1 - マイコン初級編

### 目的
- Raspberry Pi Picoを用いた開発に必要な基礎知識を得る．

### 到達目標
- 自分のPCにRaspberry Pi Picoの開発に必要な環境を構築することができる．
- Raspberry Pi PicoとPCを正しく接続し，プログラムを書き込むことができる．
- Raspberry Pi PicoをArduino IDEの基本的な関数を用いて制御することができる．
